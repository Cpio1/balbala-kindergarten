# Сайт детского сада «Балбала»

Лендинг ЖШС «Балбала» балабақшасы на Next.js (App Router), TypeScript, Tailwind CSS v4, Motion и Lucide.
Основной язык — казахский, есть полный русский перевод (переключение без перезагрузки, выбор сохраняется в браузере).

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # продакшн-сборка
npm start
```

## Где что менять

| Что | Файл |
| --- | --- |
| Название, адрес, часы работы, Instagram, **телефон, WhatsApp, ссылка на документы** | `src/config/site.ts` |
| Все тексты на казахском и русском | `src/i18n/translations.ts` |
| Секции страницы | `src/components/sections/*` |
| Цвета, шрифт, анимации, высота шапки | `src/app/globals.css` |

### Телефон, WhatsApp и документы
В `src/config/site.ts` замените `null`:

```ts
phone: "+7 700 000 00 00",
whatsapp: "77000000000",          // только цифры
documentsUrl: "https://drive.google.com/...",
```

Кнопки «Қоңырау шалу», «WhatsApp-қа жазу» и «Құжаттарды қарау» появятся/станут активными автоматически.

## Фото, логотип и видео

Положите файлы в `public/images/` — после пересборки (`npm run build` или новый деплой на Vercel) они подхватятся сами:

| Файл | Где используется |
| --- | --- |
| `public/images/logo.png` (прозрачный фон; можно `.svg`/`.webp`) | шапка, подвал, favicon |
| `public/images/main-page.png` (можно `.jpg`/`.webp`) | фото на главном экране |
| `public/images/main-page2.mp4` | видео в разделе «Біз туралы» |
| `public/images/gallery/*.jpg/png/webp` | галерея (сортировка по имени: `01.jpg`, `02.jpg`, …) |

Пока файлов нет, показываются иллюстрации-заглушки с пометкой, пустой видеоплеер не выводится.

## Деплой на Vercel

1. Загрузите проект в GitHub и импортируйте его в Vercel (фреймворк определится автоматически).
2. Необязательно: задайте переменную `NEXT_PUBLIC_SITE_URL` (например, `https://balbala.kz`), если используется свой домен — она нужна для canonical/Open Graph-ссылок. Без неё используется продакшн-домен Vercel.
